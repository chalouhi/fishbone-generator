Fishbone Generator

Give it one plan file. It draws the fishbone: the steps in order on a line that ends in the goal, with the work found along the way hanging off each step. Your file never leaves this browser.

Drop a file here or JSON or XML, as described in the file-format guide.

Three ways to use it: this page; the command fishbone <file> --svg out.svg --pdf out.pdf; or include src/fishbone.js in your own page and call Fishbone.draw(place, text). MIT licence. Source.
